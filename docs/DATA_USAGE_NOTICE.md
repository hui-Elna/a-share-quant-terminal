# 数据源与使用限制说明

> 本项目是个人研究 / 课程设计性质的本地量化终端，**不提供投资建议**。
> 本文档只做风险提示，不构成法律意见。

## 1. 数据源清单

| 数据 | 主要来源 | 说明 |
|---|---|---|
| 股票池 / 日线 / 日历 | AKShare、Baostock | 公开页面或公开接口的二次封装 |
| 实时快照 / 历史日线兜底 | 腾讯、新浪 | 公开行情接口 |
| 估值 / 板块 / 资金流 | 东方财富、同花顺 | 公开页面接口 |
| 分红明细 | 巨潮资讯 | 公开披露数据 |
| 指数 / 宽基 | 中证指数、新浪 | 公开指数数据 |
| 国债收益率 | 中债 / AKShare | 公开收益率曲线 |
| 财经新闻 | 新浪、同花顺、东方财富、华尔街见闻 | 公开 RSS / JSON / 页面 |

## 2. 使用限制

1. 仅用于个人研究、学习与课程设计；
2. **不对外分发、不用于商业用途、不提供付费服务**；
3. 不将数据或衍生结果包装为投资建议、荐股或收益承诺；
4. 不实现验证码识别、代理池轮换、反爬绕过等能力；
5. 采集遵守固定 UA 与限频（快照 ≤1 次/分钟，历史 ≤2 请求/秒）；
6. 第三方数据源的版权、许可与商用条款由原始提供方决定；本项目无法确认其商用许可，如需商用请自行取得授权。

## 3. 安全与脱敏

- `.env`、`WECOM_WEBHOOK_URL`、`DEEPSEEK_API_KEY`、`ADMIN_API_KEY` 不提交仓库；
- 日志、接口响应与数据源健康度中的错误信息会过滤 URL、token、Webhook，并截断长度；
- 演示站只使用确定性演示数据，不包含真实持仓或密钥。
